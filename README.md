# CRC CAF--Myeloid Bioinformatics Analysis

## 1. Project Overview

This repository contains the R and Python scripts used for extended
bioinformatics analyses, statistical validation, single-cell and spatial
transcriptomic analyses, and publication figure/table generation in a
colorectal cancer (CRC) study focusing on a CAF--myeloid-related gene
signature.

The scripts provide supplementary and extended analyses of the study,
including:

-   External-cohort validation and multi-cohort random-effects
    meta-analysis;
-   Prognostic model assessment, cut-off sensitivity analysis, and
    multivariable Cox regression;
-   Single-cell permutation analysis;
-   Spatial transcriptomic analyses and sensitivity assessments;
-   CAF-to-myeloid ligand--receptor prioritization;
-   Biological characterization of risk groups;
-   Generation of publication figures and LaTeX tables.

**Important:** This repository contains the scripts included in the
supplied ZIP archive. It does not contain the complete upstream analysis
pipeline, raw datasets, or all intermediate result files. Several
scripts require processed data objects and result files generated by
earlier analysis steps. Therefore, the scripts should be used together
with the corresponding input data and upstream analysis outputs.

## 4. Description of Analysis Scripts

### 4.1 R scripts: statistical analyses and validation

  ----------------------------------------------------------------------------
  Script                                   Description
  ---------------------------------------- -----------------------------------
  `deepen_01_gse17537.R`                   External validation in GSE17537
                                           using the previously trained
                                           13-gene linear predictor without
                                           refitting the model coefficients.

  `deepen_02_meta.R`                       Random-effects meta-analysis of
                                           continuous Cox effect estimates
                                           across TCGA and the GSE39582,
                                           GSE17536, and GSE17537 cohorts;
                                           includes assessment of
                                           between-cohort heterogeneity and
                                           leave-one-out analysis.

  `deepen_03_optimism.R`                   Bootstrap-based optimism correction
                                           of model discrimination in the TCGA
                                           training cohort, including C-index
                                           and time-dependent AUC assessment.

  `deepen_04_cutpoint.R`                   Cut-off sensitivity analysis using
                                           the median, tertile-based
                                           comparison (T1 vs. T3), and
                                           maximally selected rank statistics.

  `deepen_05_multivariate.R`               Multivariable Cox regression
                                           incorporating available clinical
                                           and pathological covariates,
                                           including age, stage, sex, MMR, CIT
                                           subtype, and adjuvant chemotherapy.

  `deepen_06_sc_permutation.R`             Single-cell permutation testing to
                                           assess cell-type-associated program
                                           scores and related contrasts.

  `deepen_07_spatial.R`                    Spatial analysis using slice-level
                                           correlations, bootstrap confidence
                                           intervals, paired permutation
                                           testing, and partial Spearman
                                           correlations.

  `deepen_08_spatial_13gene.R`             Spatial transcriptomic comparison
                                           of the 13-gene prognostic program
                                           and the 17-gene perturbation
                                           signature.

  `deepen_09_lr_priority.R`                CellChat-based prioritization of
                                           CAF-to-myeloid ligand--receptor
                                           interactions, including
                                           expression-matched random-pair
                                           null-model testing.

  `deepen_10_riskgroup_biology.R`          Biological characterization of
                                           high- and low-risk groups using
                                           differential expression,
                                           Hallmark/KEGG pathway enrichment,
                                           GSVA-based signature activity, and
                                           cross-cohort assessment.

  `deepen_11_figures.R`                    Generation of the main
                                           extended-analysis figures
                                           (FigD1--FigD7) from previously
                                           generated result tables.

  `deepen_12_figures_ext.R`                Generation of additional figures
                                           (FigE1--FigE8), including ROC/AUC,
                                           risk-score distribution, volcano,
                                           pathway, ligand--receptor, and
                                           spatial visualizations.

  `deepen_13_cit_stratified.R`             CIT subtype-stratified validation
                                           in GSE39582 and assessment of the
                                           risk-score-by-CIT interaction.

  `deepen_14_spatial_quality.R`            Spatial sample quality and
                                           tissue-composition assessment,
                                           including spot counts, UMI counts,
                                           detected genes, and
                                           epithelial/tumor-associated
                                           expression proxies.

  `deepen_15_cindex_nri.R`                 Comparison of the prognostic
                                           performance of the risk score and
                                           CIT subtype using Harrell's
                                           C-index, time-dependent AUC, NRI,
                                           and IDI.

  `deepen_16_fix_signature_file.R`         Reconciliation of the saved spatial
                                           signature file by replacing the
                                           17-gene score with the 13-gene
                                           program score after alignment
                                           checks; preserves a backup of the
                                           original file.

  `deepen_19_spatial_spp1_sensitivity.R`   Spatial sensitivity analysis
                                           assessing the influence of shared
                                           SPP1 expression between the 13-gene
                                           signature and myeloid marker score,
                                           including leave-one-marker-out
                                           analyses.

  `make_figures_bilingual.R`               Generation of Chinese and English
                                           versions of the study figures from
                                           saved analysis results.

## 5. Main Analysis Workflow

The scripts can be grouped into the following analysis modules:

1.  **External validation and meta-analysis:** `deepen_01_gse17537.R`
    and `deepen_02_meta.R`.
2.  **Prognostic model evaluation:** `deepen_03_optimism.R`,
    `deepen_04_cutpoint.R`, `deepen_05_multivariate.R`, and
    `deepen_15_cindex_nri.R`.
3.  **Single-cell and spatial analyses:** `deepen_06_sc_permutation.R`,
    `deepen_07_spatial.R`, `deepen_08_spatial_13gene.R`,
    `deepen_14_spatial_quality.R`, and
    `deepen_19_spatial_spp1_sensitivity.R`.
4.  **Cell--cell communication and biological interpretation:**
    `deepen_09_lr_priority.R`, `deepen_10_riskgroup_biology.R`, and
    `deepen_13_cit_stratified.R`.
5.  **Signature-file reconciliation:** `deepen_16_fix_signature_file.R`.
6.  **Figure and table generation:** `deepen_11_figures.R`,
    `deepen_12_figures_ext.R`, `make_figures_bilingual.R`, and the
    Python table-generation scripts.

This is a module-based guide, not a fully self-contained execution
pipeline. Some scripts depend on outputs from the original analysis
workflow and must be run only after their required input files have been
generated.

## 7. Software Requirements

### 7.1 R environment

The R scripts use packages from CRAN and Bioconductor, including:

-   **Data handling:** `data.table`, `Matrix`
-   **Survival analysis and prediction:** `survival`, `survminer`,
    `timeROC`, `metafor`, `maxstat`
-   **Transcriptomic analysis:** `limma`, `edgeR`, `AnnotationDbi`,
    `hgu133plus2.db`
-   **Pathway and gene-set analysis:** `fgsea`, `msigdbr`, `GSVA`
-   **Single-cell and spatial analysis:** `Seurat`, `CellChat`
-   **Visualization:** `ggplot2`, `patchwork`, `scales`, `ggrepel`,
    `ggridges`

Install the packages required by the scripts before execution. Some
Bioconductor packages may need to be installed through Bioconductor, and
package installation instructions may vary by R version.

The ZIP archive does not include a package lockfile or a complete record
of package versions. For reproducibility, record the R version and
package environment used for the final analyses.

To record the R environment:

``` r
sessionInfo()
```

### 7.2 Python environment

The supplied Python scripts use Python standard-library modules,
including `csv`, `os`, `re`, and `math`. No third-party Python
dependency is apparent from the imports in the supplied scripts.

To record the Python version:

``` bash
python --version
```

## 8. Important Notes Before Running the Scripts

1.  **Set the project working directory.** Several R scripts contain the
    hard-coded path `/root/projects/crc_caf_myeloid`. Replace it with
    the actual project directory on your computer or server before
    execution.
2.  **Check legacy paths in table and figure scripts.**
    `gen_tables_deepen13_14.py`, `make_latex_tables.py`, and
    `make_figures_bilingual.R` contain hard-coded paths referring to a
    previous local project directory. Update these paths to match your
    environment.
3.  **Check all input files.** The scripts require processed TCGA/GEO
    risk-score tables, expression matrices, Seurat objects, CellChat
    objects, spatial data, and other intermediate results. These files
    are not included in the supplied ZIP archive.
4.  **Run scripts according to their dependencies.** Figure- and
    table-generation scripts generally read previously saved results
    rather than performing the upstream analyses themselves.
5.  **Use caution with `deepen_16_fix_signature_file.R`.** This script
    modifies an existing spatial signature CSV file. It creates a backup
    of the original file if the backup does not already exist, but the
    input data should still be backed up before execution.
6.  **Check data and package versions.** Differences in dataset
    versions, package versions, and computational environments may
    affect reproducibility.

## 9. Reproducibility

The scripts are provided to improve the transparency and reproducibility
of the analyses reported in the manuscript. Publicly available TCGA and
GEO datasets should be obtained from their original repositories using
the accession numbers listed in Section 2.

To reproduce the analyses, users should:

-   Obtain the required public datasets;
-   Reconstruct the expected project directory and intermediate input
    files;
-   Install the required R packages;
-   Update local file paths;
-   Execute the relevant scripts in accordance with their input
    dependencies;
-   Compare generated tables and figures with the corresponding results
    reported in the manuscript.
